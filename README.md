# Gorila Crypto

Rama dedicada exclusivamente al subsistema cuantitativo Crypto de Gorila.

Contiene sólo captura de mercado cripto, ledger prospectivo, replay, calidad, PIT/OOS, validación, observabilidad y su infraestructura compartida directa.

No contiene APIs, datos, dashboards ni workflows de mercado argentino, acciones argentinas o equities estadounidenses.
